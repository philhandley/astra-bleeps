# Astra Bleeps

A chiptune studio for a crew of three on a tablet: a six-year-old Commander, a three-year-old Co-pilot and a grown-up Sound Engineer. Four robots (Bleep, Hoot, Buzz and Fizz) are the four sound shapes of an old game console's sound chip. Eight short missions teach waveforms, high and low, beat and rhythm, tunes, game sound effects and happy and sad chords, the Astra Nova way: a problem first, a guess before the answer, a few Big Questions with no right answer, then the crew makes something. Everything they make goes into a little game, Moon Run, which starts silent and ends with the crew's own sounds and song.

The Studio is always open: a Song Maker (Tiny mode for little fingers, Big mode with pages, chords, four channels and a tracker view), Bleep Pads, a Sound Lab, a Wave Drawer, Chord Blocks, a Jukebox and Moon Run.

Plain HTML, CSS and JavaScript with the Web Audio API; no build step and no libraries. Works offline after one visit and installs to a tablet home screen.

`PLAN.md` is the specification, `ENGINE.md` the engine contract, `research/` the sources, `DEPLOY.md` how to put it online.
